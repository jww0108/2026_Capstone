# Git2Value Frontend

Git2Value UI prototype implemented with Next.js App Router and Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` 입력 화면
- `/loading` 분석 진행 화면
- `/result` 결과 요약 화면
- `/portfolio` 포트폴리오 진단 화면
- `/jobs` 직무 매칭 화면
- `/salary` 시장 연봉 밴드 화면
- `/help` 문제해결 가이드 화면

## Assets

Reference-based assets are placed in `public/images/`.
